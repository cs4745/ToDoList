# 每周待办 - Windows桌面组件

一个简单的Windows桌面组件，用于管理每周待办事项。

## 功能特点

- 📅 每周视图展示，轻松查看整周安排
- ✅ 待办事项标记完成
- 📝 添加备注和关键操作说明
- 🎨 简洁美观的界面设计
- 💾 数据自动本地保存
- 🪟 无边框窗口，置顶显示

## 安装和运行

### 前置要求

- Node.js (建议版本 16 或更高)

### 安装依赖

```bash
npm install
```

### 开发模式运行

```bash
npm start
```

### 打包成Windows应用

```bash
npm run build
```

打包后的安装程序将生成在 `dist` 目录中。

## 使用说明

1. **添加待办**：点击底部的「+ 添加待办」按钮
2. **编辑待办**：点击待办事项右侧的 ✏️ 图标
3. **完成待办**：点击待办事项左侧的复选框
4. **删除待办**：点击待办事项右侧的 🗑️ 图标
5. **切换周数**：使用顶部的左右箭头切换周视图
6. **窗口操作**：使用右上角的按钮最小化或关闭窗口
7. **拖动窗口**：按住标题栏可以拖动窗口位置

## 数据存储

待办数据保存在用户数据目录下的 `todos.json` 文件中，路径通常为：
`%APPDATA%\weekly-todo-widget\todos.json`

## 技术栈

- Electron - 跨平台桌面应用框架
