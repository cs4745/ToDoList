# 每周待办 - Windows 桌面组件

一个轻量的 Windows 桌面待办组件，专为「按周管理」设计。单文件便携版，双击即用，数据保存在 exe 同目录，适合放在桌面或 U 盘随身携带。

## 功能特点

### 任务管理
- 📅 **每周视图**：以「本周一 ~ 周日」为区间展示，顶部显示日期范围。
- 📋 **双清单**：分为「短期待办」与「长期待办」两组，分类管理。
- ✅ **完成归档**：打勾完成的任务自动收进「已完成」面板（按完成时间倒序），主列表只留未完成的，清爽不杂乱。
- 📝 **备注 / 进度**：每条任务可填写备注或进度说明。
- 🗑️ **增删改**：随时新增、编辑文字、删除（删除有二次确认）。

### 窗口与交互
- 🪟 **无边框 + 置顶**：透明无边框窗口，始终显示在最前，不抢焦点干扰工作。
- 🖱️ **顶部菜单栏拖动**：按住窗口顶部标题栏即可拖到屏幕任意位置（按钮区域不触发拖动）。
- 🧲 **边缘吸附自动隐藏**：拖到屏幕边缘（左/右/上/下）自动吸附，并收缩成一条细边（约 6px）；鼠标滑到该边缘时窗口自动展开，离开再收回。
- 🔽 **最小化到系统托盘**：点右上角 × 不会关闭程序，而是收进系统托盘（隐藏窗口、不退出）。
  - 托盘图标 **左键单击**：切换窗口显隐
  - 托盘图标 **双击 / 右键「显示窗口」**：显示并聚焦窗口
  - 右键菜单 **「退出」**：真正关闭并退出程序
  - 托盘 tooltip 显示「每周待办」

### 数据与持久化
- 💾 **自动本地保存**：任何改动（文字、备注、勾选、删除、新增）即时写入本地文件，无需手动保存。
- 📦 **便携存储**：数据文件 `todos.json` 保存在 **exe 同目录**，换机器/拷 U 盘连 exe 带数据一起走。
- 🔄 **周切换自动归档**：应用启动时若跨过了周一，会自动把「已完成」项归档进历史，未完成的任务则顺延进入新的一周继续保留。
- ⚙️ **开机启动**：设置面板可开关「登录时启动」。
- 🔗 **桌面快捷方式**：设置面板一键在桌面创建快捷方式（自动带自定义图标）。

## 技术栈

- **Electron 28**（Windows x64，portable 单文件目标）
- 原生 Web 技术：HTML / CSS / JavaScript（无前端框架）
- 打包：electron-builder（portable 目标，自包含，无需安装）

## 安装与构建

### 环境要求
- Node.js 16+（Windows）
- 已安装依赖（`npm install`）

### 开发模式
```bash
npm start
```
以开发模式启动（窗口加载项目内的 `index.html`）。

### 打包成便携 exe（推荐）
```powershell
npm run build
```
构建完成后，自包含的便携 exe 生成在 `dist/` 目录。该 exe 已内嵌自定义图标，双击即可运行，所有数据保存在 exe 同目录。

> 注：构建脚本中的 `set NODE_OPTIONS=` 用于在当前自动化环境下禁用临时文件拦截，普通 Windows 环境运行也无副作用。

### 其他打包目标
```powershell
npm run build:portable   # 仅便携版 (portable)
npm run build:nsis       # 带安装向导的安装包 (nsis)
npm run pack             # 仅打包未压缩目录 (--dir)
```
更多说明见 [BUILD.md](./BUILD.md)。

## 数据存储位置

打包运行后，数据保存在 **exe 所在目录** 的 `todos.json` 中，例如：
```
D:\Tools\每周待办-1.0.0-便携版.exe
D:\Tools\todos.json        <- 数据在这里
```
开发模式下数据在项目根目录的 `todos.json`。

## 已知说明 / 待办
- 周切换（跨周归档）只在**应用启动时**判定；若程序从周日一直开到周一，需下次启动时才会滚周。
- 当前「未完成」任务会无限顺延，没有单独的「逾期 / 遗留」视图（如需可后续添加）。

## 目录结构
```
.
├── main.js              # 主进程：窗口、托盘、IPC、数据持久化
├── renderer.js          # 渲染进程：UI 渲染、交互、数据加载/保存
├── index.html           # 界面结构
├── styles.css           # 样式
├── assets/              # 图标等资源 (icon.ico)
├── .build_helper/       # 构建/校验辅助脚本 (图标校验等)
├── dist/                # 构建产物 (git 忽略)
└── release/             # 发布用的成品 exe (git 忽略，仅作本地 Release 附件)
```
